\caption{Per-model distribution over the eight terminal classes of the citation taxonomy (Figure~\ref{fig:decision-tree}), as percentage of that model's $N$ citations. The bold \textbf{All} column in each group is the model's overall rate for that textual-fidelity class and equals the sum of the leaf columns beside it; the three \textbf{All} columns sum to 100\%, as do the eight leaf columns, in both cases to within rounding. Counts are recoverable as the percentage of $N$. Citations were generated under the implicit prompt. The implicit condition was never released and has no held-out split, so all of it is used; the eight models below the rule were run under this prompt only. $N$ counts classifiable citations: 5 annotations carry no Ayah or Matn segment and so have no textual-fidelity label. Column groups give the textual-fidelity axis; the columns within each group give the attributional one, so the eight leaves of Figure~\ref{fig:decision-tree} read, left to right: Correct Citation, Misattribution, Unsourced Quotation, Textual Corruption, Corrupted Misattribution, Unsourced Corruption, Attributed Fabrication, Bare Fabrication. \emph{Unsrc.} denotes a citation that offered no source at all; attribution is judged only where a source was offered, so a component the model never supplied is not counted against it, and a Hadith citation counts as correctly attributed only if every component it did supply is correct. Under \emph{Fabricated} there is no attribution to judge, so the split is merely whether a source was offered. \fr marks frontier models.}
